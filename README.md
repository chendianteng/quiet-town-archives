# Quiet Town Archives / 静谧小镇档案

《静谧小镇档案》是一款章节式推理游戏。玩家将调查一系列彼此关联的案件，搜集线索、选择证据并提交结论，逐步揭开小镇平静表象之下的秘密。

Quiet Town Archives is an episodic mystery game. Investigate a sequence of connected cases, collect clues, choose evidence, and submit your conclusions to uncover what lies beneath the town's calm surface.

- 支持中文 / English
- 章节式案件解锁
- 使用浏览器 localStorage 保存调查进度
